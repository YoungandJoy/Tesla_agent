# TSLA AI Agent — Young Oh

한국투자증권 테슬라 자동매매 AI Agent

## 기능
- ⚡ 실시간 AI 매매 신호 (Claude + Web Search)
- 📋 주간 테슬라 & 세계 금융 리포트
- 📨 텔레그램 자동 알림 (BUY/SELL, 손절 경보, 정기 분석)
- 🤖 자동 모드 (15/30/60/240분 간격)

## Vercel 배포 방법

1. https://github.com 접속 → New Repository → "tsla-agent" → Create
2. 이 폴더 전체를 GitHub에 업로드
3. https://vercel.com 접속 → New Project → GitHub 연결
4. 프로젝트 선택 → Deploy 클릭
5. 배포 완료 후 URL 받기 (예: tsla-agent.vercel.app)
